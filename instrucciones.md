Como se hará:   Pues quiero q el lenguaje principal sea python, la mente detrás de todo. Pero quiero q la interfaz y todo eso sea a través de html. Prefiero q al abrir el archivo principal q deberá ser main.py, se abra una pestaña en el navegador predeterminado, dondé ahí estará todo el contenido. 
Es como que python funciona como servidor en segundo plano, mientras haces todo desde una pestaña del navegador.
¿Por qué de esto? Pues porque de esta manera será mas facil diseñar la UI y la estetica. Será lo más prolijo. Ademas si fuera todo python tendriamos q usar librerías como tkinter que están muy limitadas. Y usar solo html sería flojo computacinalmente.
Ademas de esto deberíamos guardar los datos en sql o lo que creas mejor. Pero tengamos en cuenta que si yo pruebo el programa, creo y selecciono canciones, si yo vuelvo a hacer un cambio y lo pusheo a la nuve, entonces eso no se puede subir, se tiene que quedar local. Imagino eso se trabajará desde un gitignore o algo del estilo.
